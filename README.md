# Mochi 3D — Interactive Realistic Cat

An interactive 3D cat companion sculpted, rigged, textured, and animated procedurally in Blender 5.3 and rendered in real time with Three.js + GPU fur shells.

## Features
- **Interactive Petting & Booping**: Stroke the head, cheeks, chin, ears, paws, back, or tail for zone-specific reactions, floating hearts, and procedural purring.
- **Toys & Physics**: Laser pointer tracking, grabbable/tossable 3D yarn ball with paw swatting, and salmon treat tosses.
- **Studio Customizer**: 5 coat presets (Ginger Tabby, Silver Tabby, Cream Plush, Tuxedo, Siamese), 4 eye presets (including Odd-Eyes), 4 lighting moods, adjustable GPU fur fluffiness, collar toggle, and boba-eyes lock.
- **Animations**: Idle, Purr Knead, Playful Wave, Curious Tilt, Meow, Stretch, Blep, and Sleepy Nap.

## Local Development
```bash
bun install
bun run server.js
```
Open `http://localhost:3456`.
